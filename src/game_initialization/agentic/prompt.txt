suggestions. The parent passes the complete current report to the next build attempt.

change Godot code when the finding concerns missing actors, motion, placement or

repeat asset generation for a code defect. Rerun checks after repairs.

subjects, correct orientation/grounding and clear state-dependent animations.

asset via the existing tool with an explicit issue/evidence reason. Preserve versions.
