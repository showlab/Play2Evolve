# Publication checklist

This is a release-preparation copy, not a published repository.

- [ ] Project owner selects a license and confirms rights to release all copied code.
- [ ] Verify ownership/license of retained GDScript, JavaScript and prompt resources.
- [ ] Confirm distribution terms and acquisition URLs for both external benchmarks.
- [ ] Supply public H3 deployment instructions or a supported hosted endpoint.
- [ ] Run a live Initialization → Refinement → Evolution → showcase smoke experiment in
      a fresh environment with authorized models and record its configuration.
- [ ] Run the GameASG three-stage browser workflow and Docker scoring in a fresh environment.
- [ ] Select models available to public users and verify their CLI/API compatibility.
- [ ] Add a paper citation and repository URL when those are final.
- [ ] Review the validation report, known limitations, and third-party licenses.

Do not publish credentials, generated experiment outputs, model weights, or the
ignored local test environment. Build artifacts contain only the runtime package
and project metadata. Source archives additionally contain documentation and tests.
