# Play2Evolve project page

This directory contains the static project page for Play2Evolve. It can be served by GitHub Pages from the `main` branch and `/docs` directory when Pages is enabled.

The page is a local preview until the paper metadata, author information, and release links are finalized.

## Evolution demonstrations

The page includes selected Plant Defense and Neon Coast Rush clips from successive saved versions. They are labeled by cycle and route. They are demonstrations of the evolution process, not frame-matched A/B tests.
