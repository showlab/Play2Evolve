# Lake Flight

Build a playable 2D game using Godot 4. The player guides a small red bird across
a mountain lake by pressing Space to flap. Gravity pulls the bird downward;
passing through a gap between obstacles earns a point. Collision ends the run.

Provide a title screen with controls and a Start button, a clearly readable
score during play, and a game-over screen with Retry and Return to Title buttons.
The game must also work from a normal launch without scenario arguments.

Use a consistent illustrated style. Consider animated bird wingbeats and a
subtly moving lake background as video materials. Code must retain control over
bird position, collisions, obstacles, score, and transitions. Provide clear
visual feedback for flapping, passing a gap, and colliding. Keep the game small
and responsive; no external downloads should occur during gameplay.
